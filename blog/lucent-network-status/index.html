Lucent Network status: LUX, the swap and what now

Published 2026-11-19 · Updated 2026-11-19 · 874 words

Lucent Network is the 2025 direction for the Clover project, built around the Solana Virtual Machine with a new token, LUX. The CLV to LUX swap has a published window ending 17 July 2027. Olive is the successor. Its initial framework phase covers CLV, not LUX. Check the app for current CLV terms.

Lucent Network is the step between Clover and Olive. If you hold LUX, or you are deciding whether to swap, this page sets out the public terms and where the paths lead.

Status checked 19 November 2026.

Lucent Network status and what it is

Lucent Network is the 2025 direction for the Clover project. It moved the technical base to the Solana Virtual Machine and introduced a new token, LUX, as a Solana SPL token.

The project described the change as a move toward an AI-focused network. The CLV to LUX swap was part of that change, and it opened at a 1:1 ratio.

The GitBook and the Coinbase migration page are the current public references for those terms. Check them before you act, because terms can change.

Where holders stand

There are three groups, and each has a clear path.

Holders who never swapped. Your CLV is still accepted by Olive. Use the CLV to OCLV migration guide.

Holders who swapped to LUX. LUX is not part of the initial Olive phase. Keep your Lucent records and follow the LUX status page.

Holders deciding between the two. Lucent's swap and Olive's migration are different moves. The swap takes CLV to LUX. The migration takes CLV to OCLV. Do not treat them as the same step.

LUX is not part of the initial Olive phase. A holder who swapped in 2025 should keep their records and wait for an official LUX decision.

How to check the current network status

Lucent's own documentation and channels are the place to check network status, infrastructure and any change to the swap. This page does not speak for Lucent, and it does not claim to.

What this page can state is the Olive side. Olive is the successor to Clover Finance and Lucent Network, adopted by a new team. Its initial framework phase covers CLV. LUX is a separate scope decision.

What Lucent said it was building

The 2025 announcement described a network built for AI applications, using the Solana Virtual Machine and the SOON stack. The stated goals were faster execution, lower fees, and an environment suited to agent-based applications.

The CLV to LUX swap was part of that move. It gave holders a path from the older token to the new network's token at a fixed 1:1 ratio.

This page does not evaluate whether the network delivered those goals. That is a separate question, and Lucent's own documentation is the place to check current capability and status.

How to read the current status

Network status changes. A status page written today can be wrong next month, so treat this page as a dated snapshot, not a live feed.

For Lucent itself, check the project's documentation and official channels. For the swap, check the GitBook and the Coinbase migration page, which restate the published window.

For Olive, the status is simpler. The initial framework phase covers CLV. Check the app for current terms.

What holders should verify

Before you move any asset, confirm four things.

  1. Which token you hold, CLV.
  2. Which network it is on.
  3. Which migration you are using, Lucent's swap or Olive's migration.
  4. Which official link you are following.

Most confusion comes from step three. The two migrations have different destinations and different terms. Mixing them up is the mistake worth preventing.

What about the swap deadline

The Lucent swap has a published window ending 17 July 2027. That deadline belongs to the Lucent swap, not to Olive.

Olive's migration has no deadline set. A holder who misses or skips the Lucent swap can still use CLV directly with Olive.

If you are deciding now

If you still hold CLV and have not swapped, you can use the Olive migration with CLV directly. The Lucent swap is a separate event and is not required for Olive.

Olive does not accept LUX in the initial phase. Compare the terms in each place and use the app for the current CLV terms.

Where to verify

Use the official links page for Olive, and the Lucent GitBook for Lucent. Read the scam warning before you send anything, because migration searches attract impostors.

Frequently asked questions

What is LUX?

LUX is the Solana SPL token introduced with Lucent Network in 2025.

When does the CLV to LUX swap end?

The published window ends 17 July 2027. Check the Lucent GitBook and the Coinbase migration page for the current term.

Does Olive accept LUX?

No. LUX is not part of the initial Olive phase. Its scope is a separate decision.

What if I never swapped CLV to LUX?

You do not need to. Olive accepts CLV directly.

Is Lucent the same as Olive?

No. Lucent is the 2025 direction for the Clover project. Olive is the successor, adopted by a new team, and it accepts CLV in the initial framework phase.
