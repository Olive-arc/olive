00 / Vision

Built as one system, not four disconnected products.

Olive brings together four interconnected capabilities: Connected DeFi, Quantitative Investments, Agentic Trading, and Asset and Portfolio Management.

Olive Wallet is the shared account, asset-access, and transaction layer across all four. It is not a fifth capability. The RWA Marketplace is an integrated marketplace experience, not a separate pillar.

01 / Access

Connected DeFi

Supported networks, digital assets, swaps, bridges, and decentralised financial services.

02 / Intelligence

Quantitative Investments

Research, market intelligence, strategy development, portfolio construction, and risk analysis.

03 / Execution

Agentic Trading

Agent discovery, configuration, orchestration, monitoring, and execution within explicit limits.

04 / Oversight

Asset & Portfolio Management

Unified holdings, positions, valuation, allocation, performance, income, exposure, and activity.

One identity. One wallet foundation. Shared services. Defined permissions. Independent authority.

01

Phase 1

Architecture and Technical Foundations

Objective

Define the platform architecture, shared service boundaries, wallet and ledger model, data foundations, agent infrastructure, and security requirements before scaling implementation.

Intended outcome

Approved architecture, clear service ownership, and an actionable technical backlog.

Major workstreams

  • Platform architecture and capability boundaries
  • Shared infrastructure and service ownership
  • Wallet, asset, ledger, and transaction architecture
  • Data and intelligence architecture
  • Agent identity, runtime, permissions, and orchestration
  • Security, authorization, privacy, and audit
  • Technical standards and engineering practices

Milestones

  1. Architecture and boundaries approved
  2. Wallet, ledger, data, and agent designs documented
  3. Security and authorization requirements defined
  4. Engineering standards and initial backlog available
02

Phase 2

Core Platform and Wallet Development

Objective

Build the Olive application, identity services, wallet, internal ledger, shared platform services, and administrative environment.

Intended outcome

A working account, wallet, ledger, and admin foundation ready to support the four capabilities.

Major workstreams

  • Application shell, dashboard, and design system
  • Identity, authentication, sessions, and recovery
  • Wallet account, asset, and transaction interfaces
  • Balanced ledger and transaction lifecycle
  • Deposits, withdrawals, and request tracking
  • Administrative review and operating controls
  • Shared notifications, activity, and audit foundations

Milestones

  1. Application and dashboard functional
  2. Identity and account workflows operating
  3. Wallet and ledger functions operating for approved scope
  4. Admin controls available and permissioned
  5. Integrated testing and release candidate
03

Phase 3

Connected DeFi and Portfolio Foundations

Objective

Connect supported networks, assets, swaps, bridges, DeFi protocols, and the first portfolio views.

Intended outcome

Multichain access, supported asset workflows, and initial portfolio infrastructure.

Major workstreams

  • Multichain network and RPC foundations
  • Asset discovery, metadata, and pricing
  • Swaps, approvals, and transaction states
  • Cross-chain transfer routes and reconciliation
  • Staking, lending, borrowing, and yield integrations
  • Protocol information and risk context
  • Initial holdings, positions, and activity views

Milestones

  1. Supported networks and assets available
  2. Swap and bridge workflows validated
  3. Approved DeFi integrations operating
  4. Portfolio visibility foundation delivered
04

Phase 4

Quantitative Investments

Objective

Build research, market and on-chain intelligence, opportunity discovery, quantitative strategy development, portfolio construction, and risk analysis.

Intended outcome

A research and strategy layer that informs decisions without granting execution authority.

Major workstreams

  • Market, on-chain, asset, and protocol data services
  • Screening and opportunity discovery
  • Modelling, backtesting, and strategy development
  • Portfolio construction and optimisation
  • Risk, volatility, and stress analysis
  • Quantitative research assistant
  • Research workspace and strategy library

Milestones

  1. Research and data services available
  2. Strategy development and backtesting available
  3. Portfolio construction and risk analysis available
  4. Research workflows integrated and validated
05

Phase 5

Agentic Trading and Shared Agent Infrastructure

Objective

Create the shared agent registry, runtime, tools, permissions, orchestration, monitoring, and authorized execution workflows.

Intended outcome

Agents that can act only within explicitly granted limits, with user authority preserved.

Major workstreams

  • Agent identity, registry, and capability model
  • Runtime, tools, context, and memory boundaries
  • Discovery, configuration, and deployment
  • Specialized and multi-agent orchestration
  • Authorized execution and pre-trade checks
  • Permissions, limits, monitoring, and revocation
  • Performance, accountability, and developer ecosystem

Milestones

  1. Agent registry and runtime available
  2. Creation and configuration workflows available
  3. Authorized execution within limits validated
  4. Monitoring, audit, and emergency controls operating
06

Phase 6

RWA Marketplace and Ecosystem Integrations

Objective

Build an integrated marketplace for eligible externally issued tokenised real-world asset products and their investment lifecycle.

Intended outcome

A marketplace experience connected to the four capabilities, with issuer and partner responsibilities explicit.

Major workstreams

  • Marketplace operating model and product registry
  • Issuer onboarding and product disclosures
  • Discovery, comparison, and eligibility
  • Subscription, token delivery, and lifecycle support
  • Portfolio integration and reporting
  • RWA intelligence, risk, and partner controls
  • Security, compliance, and operational readiness

Milestones

  1. Marketplace and product registry available
  2. Selected issuer and partner integrations validated
  3. Investment lifecycle and disclosures supported
  4. RWA workflows integrated with the four capabilities
07

Phase 7

Security, Testing, Launch, and Operations

Objective

Validate the integrated platform, harden security and financial integrity, complete readiness reviews, and operate a controlled launch.

Intended outcome

A validated platform with monitoring, recovery, support, and release controls.

Major workstreams

  • End-to-end integration and failure-path testing
  • Wallet, ledger, and financial integrity validation
  • Application, infrastructure, and smart-contract security
  • Agent and AI security review
  • Data, privacy, and access control review
  • Performance, resilience, and recovery testing
  • Compliance, operations, and support readiness
  • Controlled rollout and continuous improvement

Milestones

  1. Critical workflows and failure paths validated
  2. Security and financial integrity requirements met
  3. Operational monitoring and incident response ready
  4. Controlled launch approved

08 / End state

One integrated platform.

Four capabilities operating through shared infrastructure, a unified wallet experience, and defined services, permissions, and partner integrations.

Foundation

Identity, wallet, ledger, data, intelligence, authorization, agent runtime, notifications, audit, and operations.

Principle

Authority stays explicit. Research does not grant execution. Agent reasoning cannot expand its own permissions.

Direction

One coherent financial environment, with specialist experiences connected through common services.
